顶部四张统计卡

  • 在追作品 订阅总数
  • 今日更新 今天有档期的剧
  • 本周有档 本周有排播的条目数
  • 待映影片 豆瓣「即将上映」条数

⚡ 立即检查 + 🔍 搜索订阅

  • 一键手动跑一次全量检查并推送，不用等定时任务
  • 搜索框聚合五平台，结果内直接「订阅」，不离开详情页
  • 平台风控/超时原因会透传到结果区，不静默吞错

五个标签页

  • 追剧清单 剧名 / 平台 / 进度 / 排播 / 下次更新
  • 本周速览 每日档 + 周一~周日 + 待观察
  • 影视日历 排播 + 下次更新 + 进度
  • 新剧发现 豆瓣热播海报墙，一键「＋追」
  • 待映倒计时 片名 / 上映 / 还有 N 天

界面外的能力

  • 推送走 MoviePilot 通知中心，插件零推送配置
  • 静默时段暂存、晨间合并补发
  • ICS 端点 /api/v1/plugin/DramaTracker/ics 订阅到手机日历
  • 远程命令 /dt_check /dt_today /dt_search 剧名
