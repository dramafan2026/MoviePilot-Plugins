# 追剧助手 DramaTracker

MoviePilot V3 插件。五平台追剧订阅 + 更新推送 + 排播日历 + 豆瓣新剧发现，微信里即可追更。

## 功能

- **五平台搜索订阅**：爱奇艺 / 腾讯视频 / 优酷 / B站 / 芒果TV，自动过滤花絮、解说、单集切片，只留正剧。
- **每日检查推送**：新集更新 / 完结 / 断更提醒，多剧合并一条微信卡片（剧名 + 最新进度 + 更新时刻）。支持「无更新也推送」开关与静默时段（23:00-08:00 暂存晨发合并）。
- **官方排播时刻**：爱奇艺官方更新策略文案优先（如「VIP会员每日18:00更新」），其余平台按历史更新日推算星期规律。
- **追剧日历 / ICS**：插件页内置日历视图，另提供 ICS 端点可直接订阅到手机日历。
- **豆瓣新剧发现**：每日对比热播榜（frodo 官方签名接口 + 网页版自动回退），支持评分阈值、关键词黑名单、每日上限；可选**自动追剧**（按阈值自动搜索订阅，每日限量）。
- **待映倒计时**：豆瓣「即将上映」，上映当日推送提醒。
- **周报**：每周一推送未来 7 天追剧看点。
- **远程命令**：`/dt_today` 今天有什么更新、`/dt_check` 立即检查、`/dt_search 剧名` 搜索即订阅。
- **智能体工具**：`今天有什么更新`——AI 对话里直接问追剧进度。
- **iOS 快捷指令**：`GET /api/v1/plugin/DramaTracker/quick_add?apikey=...&name=剧名&platform=爱奇艺` 一键订阅。
- **工作流动作**：`追剧检查推送`，可串接进任意工作流。

## 使用

1. 插件市场安装（或把 `plugins.v3/dramatracker` 放入宿主插件目录），启用插件。
2. 「工作台 → 追剧助手」搜索剧名 → 选平台订阅；或在配置页设置每日检查时刻。
3. 推送走 MoviePilot 通知中心（沿用你在系统里配置的消息通道），插件本身零推送配置。

## 说明

- 存储/定时/通知全部使用宿主内置能力，无第三方依赖、无独立数据库。
- 豆瓣封面有防盗链，插件内置 `/cover` 代理端点带 Referer 拉图，前端与推送内引用自动转换。
- 数据键：`subscriptions`（订阅表）、`state`（检查记录/榜单快照/暂存推送）。
- 平台接口如遇风控（403/空结果），错误原因会透传到搜索页面，稍后再试即可。
